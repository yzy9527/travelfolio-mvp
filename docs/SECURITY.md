# 安全与隐私说明

当前版本使用独立 Node Worker、确认后研究的大纲流程，以及包含固定可信脚本的手册。工作流细节见 [工作流运维](SKILL-OPERATIONS.md) 与 [API 约定](API-CONTRACT.md#v2-skill-pipeline-additive)。升级或重启时同步处理 `api`、`worker` 和 `web`。

## 1. 适用威胁模型

此 MVP 用于可信任运营者控制的、小规模邀请制旅行规划。目标包括阻止普通账号读取他人数据、避免把 BYOK 泄露给浏览器、抵御常见跨站请求和注入风险，并明确模型输出的不确定性。它不提供端到端加密、对恶意宿主机管理员的防护、合规认证、独立渗透测试结论或完整企业身份管理。

公开部署前应由实际运营者对最终配置、依赖和源代码做安全评估。出发日期、住址、同行人员等可能是私人资料，请遵循最小收集原则，不把护照、身份证、支付资料、儿童详情、病史等放入提示词。

## 2. 身份、会话及隔离

- 注册需邀请码；系统没有默认管理员或通用演示密码
- 会话使用 HttpOnly Cookie；跨站写请求校验精确 Origin，已登录写请求还需要 CSRF token
- Cookie 在公开部署使用 Secure；HTTP 仅允许明确的本机开发 Origin
- 用户查询、任务轮询、版本操作和导出应始终包含服务端所有者校验；前端隐藏按钮不构成权限边界
- 管理页面只展示用户状态、聚合计数和脱敏失败摘要，不授予普通行程接口的跨用户读取权
- 登录存在保存在数据库中的 IP/账号限流；这不是分布式 WAF，也不能取代反向代理的连接限制和监控
- 管理员不得停用自己，避免误锁住唯一管理入口。管理员密码恢复使用受限宿主机 CLI

API 不启用 Express `trust proxy`。部署内的 Nginx 覆写转发头，API 不根据客户端可伪造的转发链识别来源。反向代理后的用户因此可能共用更严格的 IP 登录配额（60 次 / 15 分钟），并继续受账号维度限制。不要直接改成 `trust proxy=true`；需要精确可信代理配置与对应测试后才能调整部署拓扑。

## 3. BYOK 与服务器秘密

Key 在服务器端以认证加密形式存入数据库，主密钥由 `KEY_ENCRYPTION_SECRET` 提供；它不是数据库中的另一个字段。响应只暴露“是否有 Key”，不回传原值。Key 不写入前端 bundle、导出或常规错误提示。

以下边界很重要：

1. 应用必须在调用模型时解密 Key。拥有容器环境、进程内存或主密钥和数据库的人可能获得 Key
2. 行程正文、用户邮箱和任务内容并未因此获得字段级或端到端加密。生产宿主机磁盘与备份应另行加密
3. 丢失主密钥会使原有 BYOK 无法解密。直接替换它不是完整的密钥轮换：需先规划重新加密或要求用户重新录入
4. `.env` 和容器环境可被宿主机管理员读取。`.gitignore`/`.dockerignore` 只能防止常见误打包，不能代替密钥管理器
5. 更换 provider/base URL 时不能静默复用旧 Key。始终核对自定义地址，避免把凭据提交到不可信服务

数据库密码和加密主密钥必须分别随机生成，不复用，不放入截图、工单、命令参数或仓库。泄漏后立即撤销供应商 Key、停止可能有风险的入口，并计划会话及密钥更新。

## 4. 外部调用与网络边界

用户点击实际生成后，服务端才调用已配置模型；生成内容、约束、修改要求及必要的旧版本内容可能发送给该供应商。自定义服务由用户自行选择可信接收方。其保留政策和费用由供应商决定。

实时完整研究需要 Worker 的 Brave Search 共享凭据；相关搜索词会发送给 Brave。未配置检索时仅能使用明确标记的合成演示，不能声称完成实时研究。取消生成不能保证已经到达服务商的请求不收费；失败重试须由用户主动发起新任务。

自定义模型地址限定 HTTPS 公共网络目标，并应拒绝本机、私网、链路本地、云元数据、用户信息和重定向等危险目标。应用层校验不替代网络 egress 限制；生产环境建议额外限制到可信模型与搜索域名，尤其不要将 API 容器放进高权限内网。

Compose 的 PostgreSQL 位于内部网络且无宿主机端口；API 也不发布宿主机端口。引导管理员 `travelfolio_admin` 的凭据只传给 PostgreSQL；API 使用独立非超级用户角色 `travelfolio`，无建库、建角色或复制权限。该应用角色拥有自己的表并执行迁移，仍具备该应用数据的读写和建表权限；要求更强职责分离时应再拆出专门的迁移角色。API 位于内部网络；Worker 通过独立出站网络访问模型与搜索服务。Web 只绑定宿主机回环地址，公网通过受控 HTTPS 反向代理进入。

## 5. 模型输出、来源与导出

模型结果和搜索摘要均按不可信输入处理。输出结构必须校验；普通文本通过 Vue 默认转义渲染，不应使用 `v-html` 展示模型正文。外链只允许 HTTP(S)，地图搜索参数需编码。

“来源”表示检索证据，不等于对陈述逐项证实。航班库存、价格、订票条件、签证要求、营业时间、天气和安全事项仍需在官方渠道确认。演示数据是合成示例，应始终明显标记。

导出只能包含已授权版本的行程、约束与来源，不包含会话、BYOK、模型设置、账号信息或内部完整提示词。HTML 导出应转义所有文本、拒绝危险 URL，并作为独立文档下载。v2 手册只允许固定可信运行时的脚本 hash，模型内容不能成为脚本；应用预览使用仅允许脚本的隔离 iframe，不授予同源权限。行程本身可能含私人信息，下载后的文件不再受应用的登录和权限控制；转发前请自行检查。

## 6. 并发、取消与故障

- 生成任务保存在 PostgreSQL，不只存在浏览器中
- 同一行程存在活动任务时重复点击复用活动任务；幂等键使同一次用户意图可安全重放请求
- 生成完成仅新增候选版本，不会自动覆盖当前已采纳版本
- 采纳和回滚依据 `expectedRevision` 比较更新；冲突返回 409，需刷新后再决定
- 用户显式取消后不应再把迟到结果落为成功版本；供应商已消耗的 token 不可撤销
- API 管理状态，独立 Worker 执行任务；默认单个 Worker。任务有 60 秒租约和心跳，阶段结果保存在数据库。异常退出后的恢复取决于外部操作记录；可能已计费的调用需要用户明确确认，不能自动重试。详见工作流运维文档。

## 7. 上线检查清单

- [ ] 精确 HTTPS Origin、有效证书和自动续期，`SESSION_COOKIE_SECURE=true`
- [ ] 没有暴露 PostgreSQL/API 端口，没有公开 `.env`、备份、source map 或秘密
- [ ] 数据库及主密钥是独立随机值；主密钥备份权限独立管理
- [ ] 只使用可信模型服务，检查付费限额；默认关闭不需要的演示及搜索功能
- [ ] 用两个普通账号实际测试行程、版本、任务、导出不能越权
- [ ] 测试退出、停用、密码重置之后的会话行为
- [ ] 测试 CSRF、非法 Origin、SSRF、异常模型 JSON、恶意 HTML/链接
- [ ] 配置资源与速率上限、日志保留、监控；依赖升级前后重新运行安全测试
- [ ] 完成独立恢复演练，不只检查“备份文件存在”

以上勾选框是运营者待办，不代表已在你的部署环境执行。发现问题时请先限制入口、保护日志及证据，不要在公开 issue 中粘贴 Key、数据库、用户行程或会话 Cookie。
